Summary of what's implemented
- Backend (backend/): Express server with organized routes, controllers, models, and config. Features include authentication, CRUD for customers/products/quotations/salespersons/sites/terms, file uploads, Supabase integration, and a seed script.
- Frontend (frontend/): Vite + React app with pages for Login/Register/Dashboard/Products/Customers/Quotations/Salespersons/Terms, components for layout, PDF generation, import modal, and an API service helper.
